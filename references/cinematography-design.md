# 导演摄影：从意图到机位、构图与运动

此方法参考用户提供的《导演运镜与机位构图-SKILL-v1.3》中的机位决策、情绪、叙事功能、运动、画幅和接续分析，经归纳后用于本 skill。来源是创作启发，不是 Muse 能力或结果证明；不照搬其中的固定片长、字数、某种情绪只能对应一种镜头、必须切镜或禁止否定词等绝对规则。用户要求的主体、视角、动作、风格和首尾约束始终优先。

## 从观看体验设计镜头

1. 先确定这段画面要观众看见什么、感受什么：空间交代、人物关系、发现、反应、动作、氛围或收束等；风景、纪录、纯氛围镜头不需要强造剧情或情绪反转。有连续变化时找关键状态转折；不规定镜头数、事件数、情绪种类或强制信息镜加反应镜。
2. 对每个镜头、或一个连续镜头中的起点→过程→终点，具体设计：景别与主体可见范围；相机相对主体及地面/具体参照物的高度、距离、朝向和倾角；位置与运动；焦点、景深及可见环境；构图、主体占比、留白方向、前中后景；接点或收尾状态。不要把第一人称、平视、近景和固定机位混为一谈；视角身份、摄影机位置、摄影风格分别由用户选择或授权设计。
3. 运动须写明起点、运动类型和方向、速度或变化趋势、与主体的相对距离、停止/持续状态及终点构图。区分机位真实推拉与光学变焦，区分原位摇摄/俯仰与平移、跟拍和主体自身运动；有必要可组合可实现的运动，避免相互冲突或过载。用户要求高级运镜时，选择有叙事目的的路径并描述实际视觉结果，不默认固定镜头；用户指定固定机位则保持固定。
4. 让情绪有可见证据：例如需要强调空间空旷，可以安排人物与建筑的比例和留白；需要限制视野，可用门框或物体遮挡并明确何时露出。景别、摄影机高度和情绪之间只是可选的表达关系，不把“孤独一定远景”“悲伤一定固定”当规则；同一情绪也可用特写、声音或表演表达。机位锚在与场景一致的位置，如桌旁、船外、岸侧或车上，但不因例子添加场景。
5. 在目标画幅内设计主体及焦点、视线和运动方向的空间、地平线、边界和遮挡，安排前后景、比例参照、线条、反射和颜色亮度的视觉层次。9:16 竖屏应考虑狭窄画幅、出入画、关键物体与平台遮挡；居中或并排、横移或纵移都按画面需要决定，不把比例或安全区当作普遍固定数值。
6. 多镜剪辑按需分析角色运动轴、视线、屏幕方向、动作相位、道具持有与光线，选择合适的切点；180° 线与 30° 变化是可用的剪辑经验，不是无例外的禁令。连续一镜跨段则遵循 [真实末帧与连续镜头验收](continuity-workflow.md)，绝不为了套用“相邻镜头要换角度”而改变已经要求的连续构图。

## 交付与反推

导演表按需要说明镜头的叙事作用、机位和运动、关键可见信息、风险、衔接方式；最终视频提示词仍沿用本 skill 的详细多栏目、中英文交付和三轮审查，不套来源的 200–300 字上限。只要求修订机位或运镜时，保留用户原本的主体、动作、服装、声音和风格，其他调整须有用户授权。

参考视频的机位分析需实际看对应帧：主体占比、遮挡和相对地标可支持景别/构图判断；运动及其方向需看连续画面与视差。照片无法证实运动、具体镜头型号或精确焦段；缩放、裁切、相机旋转、主体运动和景深都可能干扰判断，地平线位置与镜头高度也不能简单一一对应。区分观察、可能解释、推测和创作方案，无法判断时标未知。对应 [视频反推](video-reverse.md)。
