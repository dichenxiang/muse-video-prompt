# 参考影像风格分析与单场景迁移

适用：用户提供或明确指定可查看的图片、视频、广告或其他影像，并要求借鉴其画面风格、色调、氛围、光线或材质。先弄清用户要迁移什么；只迁移获指定或获授权的维度，不默认复制参考画面的人物、产品、场景、构图或镜头。用户只说“这种调色和氛围”时，构图与拍摄设计仍以新场景和用户指定为准。未给参考素材时，可询问其风格描述，或在授权导演设计时基于明确假设创作；不能假装看过影像，也不能仅凭品牌名推断具体广告的视觉效果。

## 一、素材与证据

- 首先实际查看图片；视频依任务查看有代表性的开场、中段、结尾及明显光线/色彩变化处，对需要时间连续性分析的片段增加抽查。仅分析风格不等于已逐帧复刻；用户要求逐帧或完整反推时遵循 [视频反推](video-reverse.md)，报告实际视觉覆盖。未提供、无法打开、含占位符或仅有他人文字叙述时，标注无法观察，不编造参考影像的场景、色彩、设备、光源或效果。
- 将结论区分为 **画面直接观察**、**可能的解释**、**为目标场景设计**。例如看到“背景偏青、肤色相对暖”是观察；“使用了某种胶片或灯具”仅是未经证实的推测。精确色号、相机型号、ISO、调色软件和光源位置无法从单帧可靠还原时不可写成事实。
- 来源截图本身若只是讲述分析其他广告的方法，其文字只能作为作者的方法性说法，不是该广告的画面证据。作者称效果稳定也不是 Muse 的验证结果。

## 二、只分析获授权的风格维度

针对用户指定的色彩和氛围，优先建立一份简短内部风格剖面，再转成可见指令；其他维度仅在用户提出或为了落地所必需时分析。

1. **色彩层次与落点**：主色、辅助色、少量点缀色分别位于天空、背景、衣物、主体、阴影或高光的什么区域；冷暖关系、饱和度、明度和色彩面积。肤色按实际主体/素材描述，不把某个人的肤色当成所有角色的默认值。若场景无天空或人物，将颜色关系映射到相应材料，不添加不存在的对象。
2. **亮度与曝光观感**：整体明快或低调、明暗对比、高光是否保留纹理、暗部是否可辨、画面中明暗重心；用“明亮天空但主体表面细节可见”等可见效果描述，不凭视觉估测具体曝光参数。
3. **光线与空间氛围**：看得到的受光方向、柔硬、阴影边缘、逆光或反射和冷暖层次；区分可见结果与可能光源。将抽象的清新、孤独、温暖等情绪落到色彩、留白、光线和适合景别的可见表演或环境运动上。
4. **材质与影像质感**：结合观察描述皮肤、布料、金属、水面或景物的表面反射、清晰度、微对比、颗粒和运动模糊；不得从风格图虚构目标主体的外观。景深、焦点、构图、镜头运动和摄影参数只在授权迁移或用户需要时记录，并与目标景别一致。
5. **时间变化**：视频只在观察范围内记录颜色和光线变化是否稳定、是否由进出阴影、天气、火光等引发；单张图不能证明动态变化，目标视频的变化应标为设计而不是参考事实。

## 三、迁移到单场景视频提示词

先保留本片用户确认的主体、空间、动作、景别、开场与收场和机位路线。为每个拟迁移风格特征写“参考中可见特征→新场景哪个区域如何呈现→与人物/道具/环境和运动的关系”，选出少量最有辨识度且互相兼容的特征，落入提示词的【视觉风格与色彩】【光线与影调】【材质与影像质感】等适用栏目；其中动作引发的光线变化同样写进对应时间段。不要把参考素材中的人物动作、地点、标志、字幕和未授权镜头顺手带入。

当参考风格和用户指定天气、场景、肤色、光线或镜头相冲突时，优先用户对当前作品的明确设定；将可调的色彩关系重新设计，无法判断且影响关键效果时一次只问一个问题。图生视频优先尊重实际首帧已有的光影和色彩，变化必须有明确原因。特征写法是希望模型呈现的效果，不保证 Muse 精确执行或复现参考片。

示例方法，不是统一预设：用户选择“只借鉴参考的高明度冷色环境与偏暖主体”，目标是雨夜街景，则先保持雨夜、机位及主体动作；可设计较明亮的冷灰路面反射和局部暖色人物受光，同时保持夜晚可辨的暗部与光源来源。不能把参考中原有天空、人物或品牌直接加进新场景，也不能把高明度误写成整幅画面过曝。

## 四、复核与交付

1. 单场景开头、过程、结尾的色调、主次色面积、受光、材质是否一致或有清楚的变化原因？受光及景别是否让要求细节可见？
2. 仅继承用户授权的风格维度了吗？用户人物、场地、镜头与场景主线是否仍是主导？有无把他人文本描述或品牌想象成实际观察？
3. 中英文是否逐项对应，中文视频提示词仍按详细导演版及用户长度要求交付？最后执行 [三轮逐稿审查](prompt-review.md)，仅对实际看过的参考给证据描述；生成后依真实成片再迭代。
