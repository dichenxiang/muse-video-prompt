# 提示词结构与优先级

这个结构源于用户提供材料中“全片总定律→输出形式→逐层展开”的写法，作为可改写的导演工具，不假设 Muse 必然遵循格式、精确时码或文本优先级。视频提示词默认中英文各一份完整、可复制的代码块；用户明确指定语言或格式时遵从。

## 默认组织顺序

默认中文提示词依次使用【最高优先级】【全片概览】【输出形式】作为开头标题；分段改为【本段最高优先级】【本段概览】【输出形式】。英文版使用语义对应的标题。之后依据 [全片导演设计栏目库](design-coverage.md) 逐项判断并详细展开，不能只写概括性几段；用户另指定结构时遵从。

1. **最高优先级｜关键约束**：依据用户明确目标选出本片最重要、可观察的约束，如主体身份/数量、摄影机位置与景别、空间结构、关键动作及不可改变的物件。标明范围：全片、某镜头或某时间段；如后面允许变化，写清何时和如何变化。根据当次创作需要说明冲突时的取舍，不照搬别的作品的固定优先级。用清楚正向描述为主，针对具体失败风险使用必要限制。
2. **全片概览**：简短但具体地交代这个作品的主题、角色、场景、主要行为与因果、情绪走向及开场到收场。让读者理解全片实际发生了什么；不扩写与用户目标冲突的情节。单段任务即概览该段；多段作品先写作品级总览。
3. **输出形式**：说明目标是图片/视频提示词、画幅与片长、真实/动画等风格、单镜或多镜、正常/其他速度、是否对白音乐；区分实际界面设置和文字内创作指令。单段上限以实际界面或用户提供的限制为准；未知时可暂以10秒规划并标明假设，不等同于所有 Muse 版本的事实。
4. **按需展开**：参考图角色与分工；角色/关键物品、服装和外貌；空间结构；镜头、分段时间和动作；光色材质、视听与连续性。每一部分写到能被视觉生成模型理解的动作和状态，而不是标题堆砌；保留用户所需的高细节，不强制每片都有不适用的栏目。
5. **阶段与约束复核**：关键要求在总控、相关动作段落及结尾一致强调，明确时间范围；避免“全程不变”与用户要求某时变化的矛盾。多镜头分段总览标全局时间，各独立片段仅写本段局部时间和本段发生的事件，附必要全片不变量；不得指示每段重复全片剧情。每段自包含可复制并拥有自己的首尾帧方案。

## 冲突处理和来源界线

把用户显式、最近的选择与角色/道具/位置分配作为最高依据；将导演补全、参考图可见内容和其他资料区分。用户明确指定某个关键要素不允许变更时，场景、镜头和质感不能把它覆盖。如果同一用户提供的要求在相同时段不能兼容（例如既要固定机位又要摄影机平移；既要求出现标志又明确禁止该标志），若能够从明确的修订顺序判断以新指令为准；无法判断且会影响结果时用访谈一次问一个问题。不能借“最高优先级”臆造规则，覆盖用户指定视角、改变单镜为多镜或强制使用别的模型语法。

主动对齐三轮审查：首段优先级与全片叙事不矛盾；时长、空间和动作关系在时间线上成立；中英文逐项一致且每段可单独复制。重复的目的在于关键条件跨段落持续清楚，不是用重复长度取代新信息。显示的百分比、镜头术语、参考图绑定、尾帧锁定只表达目标或依界面支持，不能保证模型实现。
