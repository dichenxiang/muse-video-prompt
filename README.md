# Muse Video Prompt

面向 Muse 等文生视频工具的视频提示词 skill：通过逐题导演访谈，将文字创意扩写为详细的镜头、动作、画面和声音提示词；也支持根据参考视频逐帧整理画面、分析镜头并反推提示词。

## 安装

将本仓库内容放入支持 Agent Skills 的工具的 skills 目录，例如 Codex 的 `~/.codex/skills/muse-video-prompt/`，然后在对话中调用 `$muse-video-prompt`。具体加载方式以使用的工具为准。

## 视频分析依赖

视频反推的逐帧整理脚本需要 Python 3、FFmpeg、FFprobe 和 Pillow。脚本生成带帧号和时间戳的联系表，视觉理解仍需由具备看图能力的助手完成。

```text
python scripts/analyze_video.py <视频文件> --out <新的空目录>
```

## 使用说明

文字模式默认逐题访谈，可以告诉助手“剩下全部你决定”来结束访谈。完成设计后默认输出中文和英文两份完整提示词，并询问是否需要生成与开场镜头一致的首帧。参考视频模式会报告实际查看的帧及无法确认的内容。镜头指令与时间线是创作意图，不保证视频模型精确执行。
